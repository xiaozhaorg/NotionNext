「养虾」正在成为许多开发者的新日常——用 AI 编程智能体干活，像养一只随叫随到的龙虾。

但真正上手后，很多人会遇到两个现实问题：

- **「虾粮贵」**：每一次调用、每一轮对话、每一次调试，都是成本
- **「虾会卡」**：请求一多就被限流，智能体直接摆烂

结果是开发者开始"精打细算地用 AI"，而不是"充分释放 AI"。

最近讯飞星辰 Coding Plan 全面升级，重构了计费模式，还引入了 GLM-5.1 等旗舰模型。这篇说清楚升级了什么、值不值得上车。

## 3.9 元不限量：从 Token 焦虑到无忧畅享

开发者在「养虾」或用 AI 编程时，最怕的是**突发高并发带来的限流和超额账单**。

这次升级的核心变化：**计费逻辑从「按 Token」改成「按请求次数」**。

看似只是计费单位调整，本质是使用范式的切换——从关注"消耗了多少资源"，变成关注"完成了多少次调用"。

### 套餐变化

针对学生、独立开发者和 AI 编程新手，原「入门版」升级为 **「无忧版」**：

- **仅需 3.9 元**
- **请求次数不限量**

不管一天内让「龙虾」干多少活、发多少次请求，都不会因请求次数超标被粗暴限流。

对于专业版、高效版的职业开发者和重度企业用户，新版采用 **5 小时滑动窗口 + 周重置 + 月重置**的多维度流控：

- 不是只看当天 Token 总量
- 短期冲刺和长期稳定兼顾
- 代码冲刺的几小时内给高爆发力，夜间跑自动化任务时防止开销失控

**这个流控设计比"日限额"合理得多**——真实的开发节奏本来就是"白天密集、夜间稀疏"，一刀切的日限额反而逼着人省着用。

## GLM-5.1 加入：多款旗舰模型自由调度

如果请求次数决定了你能"下令多少次"，模型决定了你养的虾是什么水平。这次新增支持：

### GLM-5.1

智谱新一代旗舰基座：

- **长程任务显著提升**，可自主工作长达 8 小时
- 能闭环交付工程级成果
- 整体表现对齐 Claude Opus 4.6

有大型项目重构、复杂智能体搭建这类高强度需求，GLM-5.1 是这批新成员里最值得优先上手的。

### Qwen3-Coder-Next

专为编程智能体打造的高效 MoE 模型：

- 总参数 80B，**激活参数仅 3B**
- 专注长时程、多工具、可交互的真实编程任务

日常代码补全和轻量调试的首选——激活参数小意味着快且省。

### Qwen3.5-397B-A17B

原生视觉语言模型：

- 覆盖 201 种语言
- 代码生成、智能体推理、多模态理解都强

涉及图文混合输入或多语言场景时尤其合适。

**多模型自由调度的价值**：复杂算法调最强者（GLM-5.1），日常补全切最高效者（Qwen3-Coder-Next），多模态用 Qwen3.5。同一个套餐内按任务选模型，不用为不同需求买多份订阅。

## One More Thing：Skills 让龙虾长出「虾钳」

算力和模型只是「虾粮」，**Skills 才是赋予龙虾超能力的「虾钳」**。

讯飞开放平台把三个 AI 能力打包成了 Skill：

| Skill | 能干什么 |
|---|---|
| **OCR 大模型** | 自动读发票、识别表格，整理成结构化数据 |
| **离线音频转写** | 会议录音转写成纪要，自动提炼重点 |
| **超拟人合成** | 直接「开口说话」，生成带情绪的语音回复 |

这三个接入后，你的「龙虾」不再是困在终端里的纯文本虾，而是真正实现「听、说、看」，能和现实世界交互。

**实际场景**：报销时丢一张发票截图过去，它读表、填字段、生成记录——这种活以前要手动半小时。

## 值不值得上车

**适合的人**：

- 已经习惯用 AI 编程工具（Claude Code、Cline 这类）的开发者
- 被 API 限额和账单困扰的重度用户
- 需要国内稳定访问、不想折腾中转的

**不建议的**：

- 偶尔用用 AI 写代码的——免费额度可能就够
- 已经在用 Claude Code + 官方 API 且没遇到限额的
- 对模型质量要求极高、非 Claude/GPT 不用的

**3.9 元不限量请求**这个定价，对学生和独立开发者基本没有决策成本——一杯奶茶钱，试一个月就知道值不值。

如果你的主要痛点是"国内访问不稳定"或"账单不可控"，这个套餐值得试。如果痛点是"模型不够强"，那还是得看 Claude 或 GPT，见《ChatGPT vs Claude vs Gemini 2026 大横评》。

想完全免费且数据不出本机，另一条路是本地部署，见《Ollama 本地部署大模型完全指南》——有显卡的话，那个方案长期看更省钱。
