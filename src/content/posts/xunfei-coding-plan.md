「养虾」正在成为许多开发者的新日常。

但真正上手之后，很多人会遇到两个很现实的问题：

一是「虾粮贵」——每一次调用、每一轮对话、每一次调试，都是成本。

二是「虾会卡」——请求一多就被限流，智能体直接摆烂。

开发者开始「精打细算地用 AI」，而不是「充分释放 AI」。

今天，讯飞星辰 Coding Plan 迎来全新升级。

不仅彻底重构了计费模式，更率先引入智谱最新一代旗舰模型 GLM-5.1，同时新增 Qwen3.5-397B-A17B 等多款顶尖模型，让开发者能够更高效、更自由「养虾」，创造更多AI应用。

![image](https://images.unsplash.com/photo-1677442136019-21780ecad995?w=1200&h=630&fit=crop&t=3aac55d5-e9ea-81ef-9dc3-d40fff27a4da&q=50&width=1080&fmt=webp&fm=webp)

3.9元不限量

从 Token 焦虑到「无忧畅享」

开发者在「养虾」或使用AI编程时，最怕的就是突发的高并发任务带来的限流和超额账单。

此次升级，计费逻辑由「Token计费」转变为「按请求次数计费」。

看似只是计费单位的调整，但对开发者来说，本质是一次使用范式的切换——从关注「消耗了多少资源」，变成关注「完成了多少次调用」。

![image](https://images.unsplash.com/photo-1531403009284-440f080d1e12?w=1200&h=630&fit=crop&t=3aac55d5-e9ea-8179-aa65-d45038fcaee2&q=50&width=1080&fmt=webp&fm=webp)

▲ 升级版的Coding Plan套餐类型

与此同时，针对学生群体、独立开发者以及AI编程新手，原「入门版」重磅升级为 「无忧版」，仅需3.9元，即可享受请求次数不限量权益。

无论一天内让「龙虾」干多少活、发多少次请求，都不会再因请求次数超标而被粗暴限流，彻底实现「养虾自由」。

对于适用专业版、高效版的职业开发者和重度 AI 企业用户，新版套餐采用5小时滑动窗口、周重置和月重置的多维度流控策略，不是只看当天Token总量。

简单来说，就是短期冲刺和长期稳定都能兼顾——既能在代码冲刺的几小时内赋予「龙虾」极高的爆发力和并发吞吐量，又能防止夜间跑自动化任务时的意外开销失控，让「龙虾」的算力分配更加平稳、智能。

GLM-5.1加入

多款旗舰模型自由调度

如果说请求次数决定了你能给虾「下令多少次」，那么模型就决定了你养的虾到底是什么水平。

在计费逻辑调整的同时，Coding Plan 也进一步扩展了模型支持范围，满足多元化的场景需求。

在原有模型基础上，套餐新增支持：

GLM-5.1：

智谱新一代旗舰基座，长程任务显著提升，可自主工作长达8小时，闭环交付工程级成果，整体表现对齐 Claude Opus 4.6。

如果你有大型项目重构、复杂智能体搭建等高强度需求，GLM-5.1 是 Coding Plan 里最值得优先上手的新成员。

Qwen3-Coder-Next：

专为编程智能体打造的高效混合专家（MoE）模型，总参数80B，激活参数仅3B，专注于长时程、多工具、可交互的真实编程任务。

日常代码补全和轻量调试的首选。

Qwen3.5-397B-A17B：

原生视觉语言模型， 覆盖201种语言， 在代码生成、智能体推理与多模态理解方面表现卓越。

涉及图文混合输入或多语言场景时尤为适用。

这些新模型的加入，让开发者在同一个套餐内有了更多的「武器」可选。

复杂算法调最强者，日常补全切最高效者，真正的多模型自由调度。

One Morething:算力和模型只是养虾的「虾粮」，强大的Skills才是赋予龙虾灵魂和超能力的「虾钳」。

近期，讯飞开放平台也将超拟人合成、OCR大模型、离线音频转写三个优秀的AI能力打包成Skill。

借助OCR大模型，你可以让虾自动读一张发票、识别表格，再整理成结构化数据，省去手动录入的繁琐；借助离线音频转写，可以让它把一段会议录音转写成纪要，甚至自动提炼重点；

借助超拟人合成，可以让它直接「开口说话」，生成带情绪的语音回复。

这三个 Skill 接入后，让你的龙虾不再是困在终端里的一只纯文本虾，而是真正实现了「听、说、看」，可以与现实世界真实交互。
