腾讯应用宝团队于 2026 年 5 月正式发布了 **Marvis（马维斯）**，一个致敬钢铁侠 Jarvis 的操作系统层级 AI 助手。

和传统聊天机器人最大的区别：装上之后你会看到六只"小牛马"在虚拟办公室里各司其职——它们是 Marvis 内置的六个专家 Agent，24 小时在线待命。你说一句话，它们分工干活。

这篇讲实际体验。

## 六个 Agent：一个 AI 团队帮你打工

Marvis 最核心的创新是**多 Agent 协作架构**。不是"一个模型答所有问题"，而是六个各有所长的专家：

| Agent | 职责 |
|---|---|
| **主 Agent（PM）** | 听懂你的需求，拆解任务，分配给对应专家 |
| **File Agent** | 文件搜索、阅读、格式转换、文档生成 |
| **Computer Agent** | Windows 系统底层配置、硬件检测、开机项管理 |
| **App Agent** | 调用电脑上任意应用和 EXE 程序 |
| **Browser Agent** | 接管网页，数据抓取和交互 |
| **Search Agent** | 从公开资源搜索信息，附带引用来源 |

**并行工作**是它和"一步步执行"的本质区别。比如你说：

> "帮我看看哪些自启动程序没用，关掉它们"

主 Agent 会**同时**调度多个子 Agent：Computer Agent 分析开机项、File Agent 查相关程序文件、Search Agent 补充信息。汇总后给你建议，**主动要求确认，确认后才执行**。

这个"先问再做"的设计很重要——涉及系统改动的任务，AI 不该自作主张。

## 操作系统层级：让 AI 真正成为你的电脑

Marvis 的核心突破是**能直接穿透 Windows 系统层级**。

传统 AI 助手（包括各种浏览器插件、Copilot）只能执行表层操作：在你打开的软件里帮你写点什么。Marvis 直接对接系统底层 API，做到"自然语言等于系统指令"。

它可以把整台电脑变成可对话的智能对象：

- **了解电脑配置**："我这台机器能跑什么游戏？"
- **修改系统设置**："把分辨率改成 2K，缩放 150%"
- **优化开机启动项**："启动太慢了，帮我看看"
- **清理冗余文件**："C 盘快满了，清理一下"
- **硬件检测**："电池健康状况如何？"
- **网络诊断**："网络是不是有问题？"

甚至能检测硬件能否流畅运行某款游戏——这个查询涉及硬件参数比对、游戏配置要求检索、综合判断，是多 Agent 协作的典型场景。

**安全边界**：系统级操作都需要用户确认，且能看到具体要执行什么。不是"我说一句它就直接改注册表"那种失控感。

## 效率模式与隐私模式

Marvis 提供两种工作模式，按需切换。

### 效率模式（默认）

**端云协同**：复杂问题的理解与规划借助云端大模型，文件处理和执行动作尽量在端侧完成。

好处是响应快且稳——云端负责"想得深"，端侧负责"做得快"。

### 隐私模式

**端侧模型**：所有数据解析、图片识别及对话**均在本地完成，完全不上云**。

适合处理敏感文档、公司内部资料。代价是能力比云端模型弱一些，且对本地算力有要求。

### 端云协同的分层设计

有意思的是这不是简单的二选一，而是**任务分层**：

- 能在本地完成的识别、索引、预处理，尽量本地消化
- 必要时才调用云端能力

这个设计既降低 Token 消耗，也减少不必要的数据流转。**敏感内容不出本机，复杂推理用云端算力**——比"全上云"或"全本地"两个极端都合理。

## 手机远程控制：随身携带的个人电脑

Marvis 支持 **Windows / Mac / iOS / Android 多端入口**，同账号互通。

核心能力：

- **手机上查看电脑屏幕**：实时画面同步
- **实时接管操作**：手机上直接点、拖、输入
- **锁屏也能控**：手机可远程输入密码解锁

实际意义：下班路上发现电脑上有东西要处理，掏出手机就能弄，不用回家开机。或者说"一台可以随身携带的个人电脑"——算力在家，交互在手上。

**这个功能的正确用法**：应急处理 + 轻量操作。真要在手机上长时间办公，体验还是不如直接用手机——它的价值在于"不用为了一件小事跑回家"。

## 每天 1000 万 Token：真正的零成本

Marvis 上线放出重磅福利：

- **每位用户每天免费赠送 1000 万 Token**
- 无额外付费门槛
- 无需邀请码
- 完全免费开放

这个额度是什么概念？普通用户日常办公、聊天、系统操作，**日均消耗不足 10 万 Token**。1000 万 Token 够 100 天日常使用——而且是每天重置，不是总共。

对比一下：某些 API 中转站注册送几千额度用完就没了，Marvis 是每天送。对个人用户基本等于"用不完"。

## 实际体验：好在哪和不足

### 体验好的点

1. **系统级操作真的能做到**——不是演示视频里的效果，实际改设置、管启动项都可用
2. **多 Agent 并行**——复杂任务比单线程的 AI 助手快，而且分工明确
3. **确认机制**——涉及系统的改动会问，不会闷头改
4. **免费额度实在**——每天 1000 万 Token，个人用不完
5. **隐私模式**——敏感内容能完全本地处理

### 目前的不足

1. **只支持 Windows/Mac 的桌面端 Agent 能力**，Linux 用户用不上系统级功能
2. **端侧模型能力有限**——隐私模式下复杂推理明显弱于云端
3. **生态早期**——第三方应用适配还在完善，一些小众软件 App Agent 调不动
4. **并发任务的稳定性**——多 Agent 同时跑时偶尔有任务超时

### 适合谁

- **Windows 重度用户**：想用自然语言管电脑的
- **隐私敏感的用户**：需要本地处理文档的
- **经常要远程处理电脑事务的人**：手机控电脑是刚需
- **想尝鲜 AI 新形态的人**：这是目前"AI 操作系统化"最激进的尝试

### 不适合谁

- Linux 用户（系统级功能用不了）
- 只需要聊天/写作的（用普通 AI 对话产品更轻）
- 对稳定性要求极高的生产环境（还在早期）

## 小结

Marvis 标志着 AI 助手从"聊天机器人"向"操作系统级助手"的进化。

它不只是腾讯在 AI 领域的一次尝试，更代表一种新范式：**当 AI 能够真正理解并操控你的电脑时，传统的图形界面交互方式或许将被彻底改变。**

我们习惯了"找菜单、点按钮、填参数"，而 Marvis 给的是"说人话，它去做"。这个交互革命如果成立，影响的不只是效率工具，而是整个个人计算的使用方式。

想试的话现在就能装，每天 1000 万 Token 免费。建议先拿它处理几件你平时觉得烦的事——清理启动项、整理下载文件夹、查电脑配置——感受一下"AI 牛马"到底能干什么。
