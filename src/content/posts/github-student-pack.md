GitHub Student Developer Pack 是给学生党的福利包：几十个付费开发工具和服务全部免费，官方口径总价值超过 $1000。JetBrains 全家桶、DigitalOcean 额度、免费域名、Copilot——这些单独买都不便宜。

这篇讲怎么申请、哪些权益最值得领、以及注意事项。

## 申请条件

- **在校学生**（高中、大学、研究生都行，部分职业技术学校也可）
- **有学校邮箱**（`.edu` 或学校域名邮箱）——没有也能申请，用学信网证明
- **能提供在读证明**：学生证、学信网在线验证报告、录取通知书

**关键**：GitHub 账号要先注册好，且**填真实姓名**（和证明材料一致）。

## 申请流程

1. 访问 [education.github.com/pack](https://education.github.com/pack)
2. 点 **Get the Pack**
3. 登录 GitHub 账号
4. **验证学生身份**——三种方式选一：
   - 学校邮箱（最快，几分钟）
   - 上传学生证 / 在读证明（1-3 个工作日）
   - 学信网在线验证码（国内学生推荐，认可度高）
5. 填写学校信息、预计毕业时间
6. 提交，等审核

**审核时间**：学校邮箱验证几分钟到几小时；上传材料通常 1-3 个工作日，偶尔更久。

**提高通过率的几点**：

- 证明材料拍清晰，四角完整，文字可读
- 姓名、学校、日期都要清楚
- 预计毕业时间填真实的（会影响权益有效期）
- **别用假材料**——GitHub 查得出来，且会永久封号

### 国内学生特别注意

- 没有 `.edu` 邮箱很正常，用**学信网**的在线验证报告（`chsi.com.cn` 申请，有免费次数）
- 部分学校邮箱是 `学号@school.edu.cn` 格式，能直接用
- 界面是英文的，但材料中文没问题

## 注意事项

### 1. 毕业后权益会失效

大部分权益绑定学生身份，通常**毕业后 1-2 年内陆续到期**。JetBrains 教育许可、Copilot Pro 到期后不续。

所以**在校期间尽量把权益用满**，特别是：

- DigitalOcean 的 $200 别浪费，跑点项目
- 免费域名注册了就用起来，做作品集
- JetBrains 趁免费熟悉，毕业后考虑转 VS Code（见本站插件推荐）

### 2. 同一服务只享受一次

Student Pack 的权益**一辈子只能领一次**。毕业后再入学（读研）**不能重复领**。

所以别急着领一堆用不上的——想清楚再激活。DigitalOcean 的额度激活后有有效期，领了不用会浪费。

### 3. 部分需要信用卡验证

DigitalOcean、Azure 这类云服务要绑卡（防滥用），但**学生权益本身不扣费**，只要不超额度。

没有信用卡的话：

- DigitalOcean 可以用 PayPal 或预付卡
- Azure 学生版部分不需要卡
- 先领不需要卡验证的（JetBrains、Copilot、域名）

### 4. 用学校邮箱注册

如果学校提供邮箱，优先用它申请——审核最快。没有就用学信网证明。

### 5. GitHub 账号要规范

- 用户名别太随意（以后是作品集的一部分）
- 头像、简介填一下
- 开启 2FA（安全习惯从学生时代养成）

## 申请被拒怎么办

常见原因和对策：

| 原因 | 对策 |
|---|---|
| 材料不清晰 | 重拍，光线充足、四角完整 |
| 姓名不一致 | 确保 GitHub 账号名和证明材料一致 |
| 学校不被认可 | 换学信网验证报告 |
| 邮箱不是学校域名 | 用材料证明代替 |
| 已被拒过一次 | 隔几周再试，换验证方式 |

**申诉渠道**：education.github.com 的支持表单，说明情况，附清晰材料。
