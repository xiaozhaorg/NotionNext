想搭一个自己的 WordPress 博客，但一想到要买服务器、配环境就头大？

其实，现在有不少免费虚拟主机可以用，不需要任何技术基础，注册账号就能开始搭建 WordPress。

## 为什么选 WordPress？

WordPress 是目前最流行的建站系统：

- **易用性**：后台可视化操作，不需要写代码
- **生态丰富**：海量主题和插件，想加什么功能都有
- **SEO 友好**：搜索引擎收录效果好
- **社区活跃**：遇到问题很容易找到解决方案
- **可迁移**：以后想换主机，导出数据就行

## 免费虚拟主机推荐

- **PHP 支持**：完整支持 WordPress 运行环境

- **域名绑定**：支持绑定自己的域名

## 搭建步骤

### 第一步：注册账号

1. 访问 TinkerHost 官网
2. 点击注册，填写邮箱和密码
3. 验证邮箱，完成注册

### 第二步：创建站点

1. 登录后台，进入控制面板
2. 点击「Create Website」
3. 输入网站名称和密码
4. 选择 PHP 版本（建议 8.0+）
5. 确认创建，等待几秒钟

### 第三步：安装 WordPress

1. 进入站点管理，找到「App Installer」或「Softaculous」
2. 找到 WordPress，点击安装
3. 填写网站标题、管理员用户名和密码
4. 选择语言（简体中文）
5. 点击安装，等待完成

### 第四步：访问和配置

安装完成后，通过后台提供的临时域名访问网站：

- **前台**：`https://你的站点名.tinkerhost.net`
- **后台**：`https://你的站点名.tinkerhost.net/wp-admin`

用刚才设置的用户名和密码登录后台。

## 基础配置

登录后台后，先做几个基础设置：

### 1. 固定链接设置

进入「设置」→「固定链接」，选择「文章名」格式：

```
https://你的域名/文章标题/
```

这样 URL 更美观，也利于 SEO。

### 2. 安装必要插件

推荐几个必备插件：

| 插件 | 功能 |
|------|------|
| Yoast SEO | 搜索引擎优化 |
| WP Super Cache | 缓存加速 |
| Wordfence | 安全防护 |
| UpdraftPlus | 自动备份 |

### 3. 选择主题

进入「外观」→「主题」，安装一个适合的免费主题：

- **Flavor**：简洁博客风格
- **Flavor**：适合技术博客
- **Flavor**：响应式设计，加载快

### 4. 创建菜单

进入「外观」→「菜单」，创建导航菜单，添加页面和分类。

## 绑定自己的域名

如果有自己的域名：

1. 在域名管理后台添加 DNS 记录
2. A 记录指向 TinkerHost 提供的 IP 地址
3. 在 TinkerHost 后台绑定域名
4. 等待 DNS 生效

## 注意事项

使用免费主机要注意：

1. **稳定性**：免费主机偶尔会有波动，重要数据要定期备份
2. **速度**：共享主机速度有限，不要放太多大图
3. **存储**：注意空间使用，图片尽量压缩后再上传
4. **安全**：定期更新 WordPress 和插件版本
