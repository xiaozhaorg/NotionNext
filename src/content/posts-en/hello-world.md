Welcome to **Xiaozha Blog**! This is the English version of my tech blog, where I share practical guides and tutorials on:

## What I Write About

- **AI Tools & LLMs** — Hands-on tutorials for the latest AI models, API integrations, and prompt engineering techniques.
- **Cloud Computing & Cloudflare** — Deploying static sites, serverless functions, and edge workers on Cloudflare Pages, Workers, and R2.
- **Self-Hosting** — Step-by-step guides for hosting your own Jellyfin, Immich, n8n, Mealie, and other open-source applications.
- **Free Resources** — Domain deals, GitHub Student Pack tips, free API credits, and other developer resources.

## Why an English Version?

After running the Chinese blog for a while, I realized that many of the topics I cover — especially Cloudflare, Docker, and self-hosting — have a global audience. By creating English content, I can reach more readers and contribute to the international open-source community.

The Chinese version is still available at the root domain, and you can switch languages anytime using the language toggle in the header.
